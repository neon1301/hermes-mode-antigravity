# 🪜 7-Ступенчатая лестница интеграции с оборудованием (Integration Ladder)

Методология выбора архитектурного уровня интеграции для промышленного оборудования, станков, PLC и сенсоров (в связке со специалистом `@alexey`).

---

## 🏛️ Принцип «Экспорт — спроектированный путь» (Export is a Designed Path)
В промышленной автоматизации прямая запись в управляющие регистры контроллеров и исполнительные механизмы станка несёт физические риски аварий и травм. Любая интеграция выстраивается по иерархии надёжности от готовых и безопасных каналов к низкоуровневым протоколам. Пакетная выгрузка и периодический экспорт рассматриваются как полноправный спроектированный маршрут интеграции, а не «костыль».

---

## 🪜 7 Ступеней лестницы интеграции

### Ступень 1: Vendor MCP (Официальный MCP-сервер производителя)
- **Приоритет:** Наивысший (Tier 1).
- **Суть:** Использование официального Model Context Protocol сервера, поставляемого вендором оборудования (Siemens, Schneider Electric, Beckhoff, Omron).
- **Плюсы:** Поддержка вендора, встроенный контроль безопасности и аутентификация.

### Ступень 2: Community MCP (Проверенный MCP-сервер сообщества)
- **Приоритет:** Высокий (Tier 2).
- **Суть:** Открытые сертифицированные MCP-коннекторы сообщества (например, для стандартных Modbus TCP / OPC UA / MQTT профилей).
- **Плюсы:** Быстрое подключение к стандартным шинам без написания кастомных бинарных адаптеров.

### Ступень 3: Typed API Wrapper (Типизированная обёртка)
- **Приоритет:** Средний (Tier 3).
- **Суть:** Разработка или использование типизированных библиотек-обёрток над документированными REST/gRPC/WebSocket API шлюзов IoT (например, Moxa, Advantech, Siemens MindSphere).
- **Плюсы:** Строгая статическая типизация, предсказуемая валидация DTO контрактов.

### Ступень 4: Read-Only Database View / Replica (Срез БД станка)
- **Приоритет:** Умеренный (Tier 4).
- **Суть:** Прямое чтение телеметрии из выделенного безопасного SQL/NoSQL-представления (View) или Read-Only реплики производственной базы данных (SCADA Historian, InfluxDB, TimescaleDB).
- **Ограничение:** Строго `GRANT SELECT` — запрет любых `INSERT/UPDATE/DELETE`.

### Ступень 5: Bridge Service (Изолированный микросервис-мост)
- **Приоритет:** Низкий (Tier 5).
- **Суть:** Выделенный сервис-адаптер на .NET/Python/Go, инкапсулирующий сырой сокетный обмен (Modbus TCP, EtherNet/IP, Profinet), очереди с буферизацией (Outbox/Channel) и защиту от `CA2022 Stream.Read` дефектов.

### Ступень 6: Screen Automation (Автоматизация HMI/Интерфейсов)
- **Приоритет:** Резервный (Tier 6).
- **Суть:** Взаимодействие через пользовательский интерфейс операторской панели HMI (UI Automation, OCR, Windows Accessibility), когда прямой доступ к протоколам аппаратно заблокирован.

### Ступень 7: Scheduled CSV/JSON Export (Регулярный экспорт файлов)
- **Приоритет:** Фундаментальный спроектированный путь (Tier 7).
- **Суть:** Настройка станка или OPC-сервера на периодическую циклическую выгрузку телеметрии в структурированные файлы (CSV, JSON, XML) в защищённый каталог обмена (SFTP, сетевая папка).
- **Плюсы:** 100% изоляция станка от сетевых атак, отсутствие блокировок, полная проверяемость и простота резервного копирования.
