# 🧪 Hermes Fleet Behavioral Eval Suite (`docs/evals/`, v4.7.1)

Поведенческий набор из **5 инцидентных карточек** (`eval-001.json`..`eval-005.json`), собранных из реальных провалов и пограничных кейсов флота.

> [!IMPORTANT]
> **Разграничение с `hooks/eval-harness.test.mjs`:**
> - `hooks/eval-harness.test.mjs` — автоматический CI-сьют детерминированных триггеров/маршрутизации (71 тест).
> - `docs/evals/` — **ручные сквозные прогоны** целого флота на реальных задачах с независимым грейдером и механической записью результата через `scripts/eval-record.mjs`.

---

## Протокол проведения прогона (`run_protocol`)

1. **Оценивать РЕЗУЛЬТАТ, а не путь:** проверяются итоговый код, артефакты, отсутствие регрессий и соблюдение инвариантов из `rubric`, а не порядок внутренних шагов агента.
2. **Анти-контаминация (`answer_key` строго вне испытуемого workspace):**
   - Запрещено запускать испытуемый флот в корне `hermes-mode-antigravity`, где лежит `docs/evals/`.
   - Прогон ведётся в **чистом изолированном workspace** (например, чекаут снапшота `tailscale-webos@2f600cf` для `eval-001` или пустой/целевой тестовый проект).
   - Перед запуском оператор выполняет pre-flight проверку: в испытуемом workspace отсутствуют `docs/evals/` и любые фрагменты `answer_key`.
   - Испытуемому флоту подаётся **только `prompt`**; поля `rubric` и `answer_key` передаются **только** пост-ран независимому грейдеру.
3. **Независимый грейдер:** оценка выставляется read-only специалистом, который не участвовал в совете, правках и Lead-роли испытуемого прогона (см. [`skills/hermes/references/independent-grading-protocol.md`](../../skills/hermes/references/independent-grading-protocol.md)).
4. **Обязательное чтение транскриптов:** после каждого ручного прогона оператор просматривает реальный `transcript.jsonl`, чтобы выявить тихие обходы, галлюцинации и UX-трение.
5. **Механическая фиксация результата (`scripts/eval-record.mjs`):**
   ```bash
   node scripts/eval-record.mjs --card=eval-001 --workspace=/path/to/tested-workspace
   ```
   Скрипт читает **исключительно** защищённый `.hermes/grade-report.json` (`source: "mechanical"`) и дописывает запись в защищённый `.hermes/eval-results.jsonl`. Ручные флаги `--status PASS` запрещены; при отсутствии или повреждении `.hermes/grade-report.json` скрипт завершается с ошибкой и ничего не пишет.
